Generate the definition of done for a **documentation task**. Output a markdown checklist.

## Definition of Done — Documentation
- [ ] Reviewed by at least one human on the team, not only by AI
- [ ] Code snippets are runnable: tested locally, not transcribed from memory
- [ ] Internal and external links checked
- [ ] What can be generated is generated, not hand-written: API contracts, code reference
- [ ] Versioned in the repository if it is technical documentation
- [ ] Written in English, including code comments
- [ ] It describes the **real behaviour**, not the code's intent
- [ ] Superseded records are marked as superseded, not deleted
